# ✨ Neon Aura AR

A futuristic AI-powered hand tracking web application built using **MediaPipe Hands**, **HTML5**, **CSS3**, and **JavaScript**. The application uses your webcam to detect real-time hand gestures and creates immersive visual effects with interactive sound effects.


## 📸 Overview

Neon Aura AR transforms your webcam into an interactive augmented reality experience where hand gestures trigger stunning particle animations, neon effects, and dynamic sounds.


## 🚀 Features

- 🖐️ Real-Time AI Hand Tracking
- 🤖 Multi-Gesture Recognition
- ✨ Neon Particle Effects
- 💥 Explosion & Shockwave Effects
- 🎨 Multiple Visual Themes
- 🌌 Matrix Background Animation
- 🔊 Gesture-Based Sound Effects
- 📊 Live FPS Counter
- 💎 Modern Glassmorphism UI
- 📱 Responsive Design

| Gesture | Action | Sound |
|----------|--------|-------|

## ⚙️ Installation

### 1. Clone the Repository

```bash
git clone https://github.com/aastha-waghade/neon-aura-ar.git
```

### 2. Open the Project

Open the project folder in **Visual Studio Code**.

### 3. Run the Project

Use the **Live Server** extension.

Or run:

```bash
python -m http.server
```

Then open:

```
http://localhost:8000
```

### 4. Allow Camera Access

- Open the website.
- Allow webcam permission.
- Click **Enter Experience**.
- Start using hand gestures.
